# ASCAutoPayroll

A Selenium-powered automation tool for UMBC student timesheet entry. It scrapes attendance/visit records from the TRAC Cloud system, parses and rounds the raw clock-in/clock-out times into billable increments, and then auto-fills the resulting entries into the UMBC PeopleSoft (PSHR) timesheet portal — removing the need to manually transcribe hours every pay period.

## How it works

The tool runs as an interactive CLI with two main actions:

1. **Process a Timesheet** — walks through the full pipeline below
2. **Exit** — closes the browser and quits

### Pipeline

1. **Select a pay period** — `Handler.select_timeblock()` reads `timeblock.env`/`timeblocks.csv` and presents a fuzzy-searchable list of upcoming two-week periods (generated by `TimeBlockGenerator`).
2. **Scrape attendance data** — `UMBCTimesheetScraper` logs into TRAC Cloud, waits for you to confirm the page has loaded, and saves the rendered HTML listing to disk (`Attendance Listing.html`).
3. **Parse and round times** — `AttendanceParser` extracts visit rows from the saved HTML with BeautifulSoup, rounds start times to the nearest hour and end times to the nearest 15 minutes, computes billed hours/duration, and exports a per-period CSV along with an estimated gross/net pay summary.
4. **Auto-fill the timesheet** — `TimesheetAutomator` logs into the UMBC PeopleSoft timesheet page, switches into the correct iframe, and types each parsed row (date, start, end, break) into the web form, adding new rows as needed.

## Requirements

- Python >= 3.13
- [uv](https://docs.astral.sh/uv/) for dependency management
- Firefox (automation uses `selenium`'s Firefox WebDriver via a dedicated profile)

Dependencies (see `pyproject.toml`): `selenium`, `pandas`, `beautifulsoup4`/`bs4`, `lxml`, `questionary`, `pynput`, `pyautogui`, `keyboard`, `evdev`, `dotenv`, `pyinstaller`.

## Setup

1. Install dependencies and run:
   ```bash
   ./run.sh
   ```
   which is equivalent to:
   ```bash
   uv sync
   uv run python main.py
   ```

2. On first launch, `ConfigSettings` creates a config directory at `~/.config/autopayroll/` containing:
   - `settings.env` — credentials and paths (see below)
   - `timeblock.env` / `timeblocks.csv` — auto-generated list of upcoming pay periods
   - `data/` — where scraped HTML and per-period CSV exports are saved

3. Fill in `~/.config/autopayroll/settings.env`:
   ```env
   ENV_PATH=""
   ROOT_DIR=""
   PROFILE_DIR=""     # Path to a Firefox profile (used for persistent login/session state)
   CONFIG_DIR=""
   CONFIG_PATH=""
   UMBC_USR=""        # UMBC username
   UMBC_PAS=""        # UMBC password
   ```
   At minimum, `PROFILE_DIR`, `UMBC_USR`, and `UMBC_PAS` must be set — the app will warn on startup if any are missing.

## Usage

```bash
uv run python main.py
```

Then follow the interactive prompts:

1. Choose **Process a Timesheet**.
2. Select a pay period from the fuzzy-search list.
3. Let the browser navigate to TRAC Cloud, log in, and load your attendance listing; confirm with **Yes** once the page has fully loaded.
4. The tool parses the listing, prints a summary of billed hours and estimated pay, and saves a CSV to the config data directory.
5. The browser then navigates to the UMBC PeopleSoft timesheet page and auto-fills each row; press Enter when prompted to close the browser once entries are submitted.

## Notes

- Pay rate for the pay estimate is currently hardcoded in `AttendanceParser` (`pay_rate=17.5`); adjust as needed.
- The Firefox profile directory is reused across runs to help preserve login/session cookies (e.g., Duo two-factor state), reducing repeated 2FA prompts.
- Generated artifacts (`timeblocks.csv`, scraped HTML, per-period CSVs) are written under the user config directory, not the project directory, so re-running the tool won't clutter the repo.
